# v0.14.1 - A dropped flag

Released 2026-09-18.

`make prune ARGS=--dry-run` ran the real prune.

Not breaking. No migration.

See [CHANGELOG.md](../CHANGELOG.md) for the itemised list.

## Upgrading

```sh
git pull
uv sync
```

## What happened

Make accepts a variable whether or not the recipe uses it, and says nothing
either way.
`prune:` invoked `scripts/prune.py` with no arguments, so `ARGS=--dry-run`
was taken, dropped, and a request to report what would be deleted became a
request to delete it.

Nothing in the output distinguished the two before it ran.
Afterwards it did - a dry run prints `prunable`, a real run prints
`deleted` - but by then the rows are gone.

The instance this was found on lost nothing: every table came back `0 of`,
because the deployment was new enough that no row had aged past its
retention.
That is luck, not a safeguard.

## The fix

The `seed` and `prune` targets pass `$(ARGS)` through:

```make
prune:
	.venv/bin/python scripts/prune.py $(ARGS)
```

So the flag reaches argparse, which either honours it or rejects it:

```
$ make prune ARGS=--bogus
prune.py: error: unrecognized arguments: --bogus
make: *** [prune] Error 2
```

`seed` is included because it has the same shape.
`make seed ARGS=--reset` would have quietly skipped the truncate, and the
loader's refusal to run against non-empty tables is what would have caught
it - a different message for a different reason.

The dedicated targets are unchanged and remain the shortest way in:

```sh
make prune-dry-run
make prune
make prune-blacklist
```

## Guard

`tests/test_makefile.py` asserts that every tab-indented recipe invoking a
script under `scripts/` contains `$(ARGS)`.

A pattern rather than a review, because the failure is silent by
construction: a target written without `$(ARGS)` behaves correctly until
someone passes a flag to it.

A second test asserts the match set is not empty, so a rename that stops
the first test from matching anything fails rather than passing vacuously.

Verified by reintroducing the bug and confirming the test named the
offending recipe.
